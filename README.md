# Dum & Co. — Premium Indian Restaurant Web Platform

A full-stack, enterprise-grade restaurant web platform and admin management system for **Dum & Co.**, engineered using React + Vite, customized design tokens extracted directly from Google Stitch, and backed by Supabase.

## Documentation Index
- [DESIGN.md](./DESIGN.md) — Complete Design System specification, typography, colors, elevation, and component rules.
- [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md) — Screen inventory (11 Customer + 17 Admin Dashboard) and asset catalog.
- [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md) — Master 8-Phase execution plan and progress tracker.

## Architecture
- **Customer Frontend**: 11 dedicated pages covering discovery, interactive menu, portion customization, cart & checkout, and real-time order tracking.
- **Admin Dashboard**: 17 management screens covering live orders, menu catalog, categories, promotions, customer CRM, analytics, and operational settings.
- **Design Language**: Warm Terracotta (`#C2410C`), Saffron Brass (`#B45309`), Parchment Canvas (`#FAF7F2`), editorial serif typography (`Playfair Display`), and crisp modern geometric sans (`Plus Jakarta Sans`).
